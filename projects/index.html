Projects

Sensor Fusion for Assessing the Condition of a Motor

Used different sensors like a temperature sensor, current Sensor, and voltage sensor to track behavioural changes of an N20 gear motor when the volage change occurs. We used ESP 32 to integrate the sensors and capture the sensor readings in real time.

Vision-Based Autonomous Self-Driving Car

This self-driving car was built from scratch with a custom 3D-printed body. It uses two main computers to work: a Raspberry Pi acts as the brain to look at the road and plan the path, while an Arduino reads sensors to steer and move the wheels. Custom C++ code connects everything so the car can drive itself.

17 DOF Humanoid Robot Assembly

The process involved connecting the servo motors and wiring, ensuring all components were integrated to allow for fluid motion. It was a valuable learning experience in managing a complex mechanical build.

Voice and Radio Controlled Robot

The robot operates using an Arduino microcontroller and an HC-05 Bluetooth module. A custom Android application was developed to capture voice commands and transmit them wirelessly to the robot via Bluetooth, enabling direct voice-activated movement and control.

Obstacle-Stopping Robot

This early robot uses an Arduino and a sonar sensor to look for objects in its path. If the sensor detects something ahead, the robot stops moving completely. The project is a basic test of sensing obstacles and controlling motors.

Mini Obstacle-Avoiding Robot

This small robot is powered by a custom JRC board and uses a sonar sensor to scan the path ahead. When it detects an object in its way, the robot automatically changes direction to steer around the obstacle and keep moving.

Knock-Pattern Door Unlocking Mechanism

This door lock opens only when it hears a specific knock pattern. It uses a buzzer as a sensor to listen for the knocks and an Arduino to check if the rhythm matches a saved code. If the knocks match exactly, the door unlocks automatically.

Real-Time RFID Authentication and Access Control

This door access system uses an ESP8266 and an RFID reader to check entry tags. When a tag is scanned, it unlocks the door using a servo motor, provides an audio signal via a buzzer, and logs the tag ID and access result to a local database.

Autonomous navigation and obstacle-avoidance system using the Webots simulator

An autonomous navigation system developed in the Webots simulator, driven by a custom Python controller. The robot uses waypoint tracking for path planning and real-time spatial awareness via simulated proximity sensors to detect and avoid objects by adjusting trajectory and speed. This architecture demonstrates robust control logic for dynamic environments, with potential applications in autonomous surface crack detection.
